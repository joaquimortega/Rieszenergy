# Rieszenergy

Lean 4 formalization and supporting manuscript/code for the BEMOC negative
Riesz-energy project.

The canonical Lean entry point is `BEMOCFormalization.lean`. Build it with:

```bash
lake build BEMOCFormalization
```

See `LEAN_FORMALIZATION.md` for the verified scope and remaining mathematical
obligations, and `FORMALIZATION_BLUEPRINT.md` for the project blueprint.
